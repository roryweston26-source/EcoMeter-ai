You pay nothing for any of these

Every model below is free to use. No subscription, no per-message charge — $0.00 is what it costs you. The API rates in the last two columns are what the same model costs a developer calling it through the provider’s API: they are here to show what the free tier is worth, not what you are charged. What the providers won't tell you

—

So "how much is my plan worth" can't be answered from the ceiling for most plans. What can be answered, from published API rates alone, is the other direction: how long you'd have to use a plan each day before it beats paying per token. That's the break-even column — and it's the one worth reading. As of August 2026 not one plan here has a cap solid enough to compute a ceiling from, so that column is now mostly a record of what nobody will tell you. Where a figure did exist, it needed more hours a day than anyone is awake for — which was already the point: the cap was never what limited the plan's value to you. Your time is.

Break even = what the same usage would cost at that provider's own API rates. It's an estimate built on an assumed message size and, for models that think before answering, an assumed amount of thinking — open "show the math" on any row to see every input. The API isn't the product, so treat it as a floor on value, not a full accounting: the same models arrive with no chat interface, no memory or projects, no file handling, no connectors or web search wired up, and rate limits of their own. A plan that prices out at $4 of tokens can still be worth $20 — this column tells you what the tokens cost, not what the product is worth to you. Two real costs sit outside it, pulling opposite ways: prompt caching isn’t modelled, which makes real API cost lower and break-even harder to reach, and neither is the per-search fee every provider here except DeepSeek charges on top of tokens ($5–$14 per 1,000 searches), which makes it higher and break-even easier. If your chat searches the web a lot, the true figure is below the one shown.
