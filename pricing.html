So "how much is my plan worth" can't be answered from the ceiling for most plans. What can be answered, from published API rates alone, is the other direction: how long you'd have to use a plan each day before it beats paying per token. That's the break-even column — and it's the one worth reading. Where a ceiling does exist, it usually turns out to need more hours a day than anyone is awake for, which tells you the cap isn't what limits the plan's value. Your time is.

Break even = what the same usage would cost at that provider's own API rates. It's an estimate built on an assumed message size — open "show the math" on any row to see every input. The API isn't the product, so treat it as a floor on value, not a full accounting. Prompt caching isn't modelled, which makes real API cost lower and break-even harder to reach.
